# Manbalar va tekshiruv eslatmalari

- Flutter SDK manual install: https://docs.flutter.dev/install/manual
- Flutter Android setup: https://docs.flutter.dev/platform-integration/android/setup — Linuxda Android SDK va command-line tooling; SDK package litsenziyalari.
- Flutter Android release: https://docs.flutter.dev/deployment/android — `flutter build apk`, APK joylashuvi va telefonda o‘rnatish.
- Flutter Windows setup: https://docs.flutter.dev/platform-integration/windows/setup — Visual Studio, alohida VS Code bo‘lmagan IDE, va Desktop development with C++ talabi.
- Flutter Windows distribution: https://docs.flutter.dev/platform-integration/windows/building — `.exe` bilan birga Flutter DLL va `data` papkasi ham yetkaziladi; ZIP tarqatmasi mumkin.
- Speech-to-text Flutter plugin: https://pub.dev/packages/speech_to_text — Android/Windows build qo‘llanadi; Windows speech recognition beta va production-ready emasligi qayd etilgan.
- Flutter TTS plugin: https://pub.dev/packages/flutter_tts — Android va Windows native text-to-speech.
- Secure storage plugin: https://pub.dev/packages/flutter_secure_storage — Android/Windows secure storage; Windows C++ ATL talab qilinishi mumkin.
- Offline English headwordlar: https://github.com/first20hours/google-10000-english — repository README ro‘yxatni Google Trillion Word Corpus n-gram frequency analysis asosida tuzilgan 10,000 common words deya ta’riflaydi.
- Raw frequency list: https://raw.githubusercontent.com/first20hours/google-10000-english/master/google-10000-english.txt

**Litsenziya eslatmasi:** tekshirilgan GitHub README matnida alohida litsenziya ko‘rsatilmagan va repository `LICENSE` URLidan matn olinmadi. Shu sababli ro‘yxatni ommaviy yoki tijoriy tarqatishdan oldin manba-repository egasining amaldagi foydalanish shartlarini alohida tasdiqlang. Uzbek tarjima, IPA, CEFR va misollar AI yordamida ishlab chiqilgan; bu professional til muharriri tomonidan tasdiqlanganini anglatmaydi.
